# IZODOM Кыргызстан

Сайт официального партнёра технологии IZODOM в Кыргызстане — несъёмная опалубка
для строительства энергоэффективных и пассивных домов.

## Возможности
- Многостраничный сайт (главная, технология, продукция, проекты, калькулятор, партнёрам, о компании, блог, контакты)
- Переключение языков: **русский / кыргызский** (с сохранением выбора)
- Рабочий калькулятор стоимости, слайдеры, формы, адаптивная вёрстка
- Одностраничная презентация в одном файле: `izodom-prezentaciya.html`

## Запуск локально
```bash
python3 -m http.server 8000
```
Затем откройте http://localhost:8000

## GitHub Pages
Репозиторий готов к публикации через GitHub Pages (Settings → Pages → Deploy from branch → main → /root).
Главная страница — `index.html`.

## Примечания
- Видео (`assets/video/`) и папка исходных материалов (`_materials/`) исключены из репозитория
  из-за лимита GitHub (100 МБ на файл). Видео стоит разместить на YouTube и встроить ссылкой.
- Контакты (телефон, e-mail, адрес) — заглушки, замените на реальные в `js/main.js` и HTML-страницах.
